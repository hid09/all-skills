## 📝 沉淀的规则（已记入 PROGRESS.md）

1. **JS 字符串里出现 `</script>` 必须拆开写**（如 `'<' + '/script>'`），否则 HTML 解析器提前关闭 script，后续 JS 全废
2. **PowerShell 写文件给浏览器读时，必须 UTF-8 with BOM**：`[System.IO.File]::WriteAllText($p, $t, (New-Object System.Text.UTF8Encoding $true))`，否则 file:// 下 Chrome 按 GBK 猜测 → 中文乱码
3. **React Flow 的 edge 会因 handle 不存在而静默丢失**，map handle 时必须白名单兜底
4. **PowerShell 5.1 读 .ps1 默认按 GBK 解析**，脚本本身也必须 UTF-8 with BOM，否则中文/emoji 乱码
5. **`serializeState` 只信 `e.data.dashed`，不能看 `e.style?.strokeDasharray`**，因为 `animated:true` 也会注入 dasharray，会误判所有边为虚线
