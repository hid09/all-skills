# Reference and shopping research

## General source rules

Separate observed facts, user-provided claims, and stylistic inference. Attach a source and capture time to volatile facts. If a source is inaccessible, say so and continue from the information available; do not fill gaps with fabricated prices, weather, stock, links, or trend claims. Respect login barriers, robots rules, copyright, and rate limits. Keep research optional so the Skill remains useful offline.

## Xiaohongshu

Use public pages, search results, or links/images supplied by the user. Availability can vary with login and anti-automation controls, so do not depend on bulk scraping. For each useful reference, extract:

- source URL and capture date;
- creator or account when visible;
- style tags;
- silhouette and proportion rules;
- color, texture, layering, and shoe rules;
- which owned items can reproduce the idea;
- the missing item needed for a closer version.

The output should explain the reusable styling method rather than claim that the user's result will look identical to the reference.

## Trend synthesis and aesthetic calibration

Use at least two independent references when making a current-trend claim where possible. Record the source URL, capture date, visible location/season context, and confidence. Separate:

- **Observed fact:** what the reference visibly contains.
- **Trend rule:** a reusable pattern inferred from multiple references.
- **Personal fit:** whether the rule matches the user's proportions, preferences, climate, occasion, and existing wardrobe.

Offer three intensity levels when useful: conservative, balanced, and expressive. Explain what changes between them and identify the visual anchor. If public references are unavailable, ask for screenshots or links, or give a timeless style analysis without claiming current trend status.

## Weather

Use a weather tool only when the user asks for current/forecast-sensitive planning and the city is known. Record location, local time, forecast window, temperature range, precipitation probability/type, and wind when relevant. If no weather tool is available, request those values from the user or provide conditional layers; never present a remembered climate average as current weather.

## Taobao

Research only after a wardrobe gap is identified. Search for concrete specifications (category, color, fit, warmth, material, budget) and return candidate links with title, price, material, size information, shipping/return caveats, source, and uncertainty when visible. Prices, stock, and listings change, so treat links as candidates and recheck before purchase. If search is unavailable, return the specification and query terms only. Never place an order automatically.
