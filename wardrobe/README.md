# 本地衣橱工具

本工具与 [wardrobe-stylist Skill](../skills/wardrobe-stylist/SKILL.md) 配套：网页录入自己的衣物，Agent 读取衣橱并提供穿搭建议。首次安装与开始使用见 [套件说明](../README.md)。新用户从空衣橱开始，无需个人迁移文件。

要求 Node.js 22.5 或更高版本（推荐 Node.js 24+；当前实现使用 Node 原生 SQLite）。

## 启动

在项目根目录执行：

```powershell
node wardrobe/app/server.js
```

浏览器打开 <http://127.0.0.1:4173>。

停止服务：在运行服务的终端按 `Ctrl+C`。

## 数据位置

- 原图：`wardrobe/data/images/original/`
- 展示图：`wardrobe/data/images/thumbs/`
- 数据库：`wardrobe/data/wardrobe.db`
- AI 清单：`wardrobe/data/wardrobe.json`
- 回收站：`wardrobe/data/trash/`

当前实现说明：展示图目录会保留一份与原图对应的副本，界面通过 CSS 完成缩略展示；后续如图片量很大，可再接入图片缩放处理。
## 同一网络访问

默认启动只允许本机访问：

```powershell
npm start
```

如果要让同一 Wi-Fi 或局域网内的其他设备访问，在启动时绑定局域网地址：

```powershell
$env:HOST="0.0.0.0"
npm start
```

然后在运行电脑上执行 `ipconfig`，找到当前局域网 IPv4 地址，例如 `192.168.1.23`。其他设备在同一网络中打开：

```text
http://192.168.1.23:4173
```

当前版本没有账号和密码，开启局域网访问后，同一网络内能访问该地址的人也能上传、编辑和删除数据。只建议在可信家庭网络中临时使用；公共网络、办公网络或需要长期使用时，应先增加登录验证。

## 图片录入建议

- 推荐主图：衣物平铺在床上或地面，尽量拍完整、光线均匀、减少明显褶皱；
- 推荐补充图：背面、领口、面料、图案和标签等细节；
- 商品详情页的模特图可以上传，适合作为版型、上身效果和商品搭配参考；
- 商品图中的模特、背景和其他搭配单品不应被当作用户衣橱里的真实衣物；
- 后续可在单品说明中注明“本人实拍”“商品图”“模特参考”等来源。照片管理：一个上传批次默认创建一个单品；每张照片可单独标记为实拍、模特、商品详情图或其他。进入单品卡片后可逐张修改标签、补充照片或删除照片。
